# Псалом 18 — вариант c

## О чём песня
Свидетель разворачивает перед слушателем картину Божьего ответа: дрожащая земля, тучи и рука, поднимающая человека из воды. Рассказ заканчивается не битвой, а благодарением среди народов.

## Эмоциональная арка
Зов → грозное явление → спасение → тихое величание.

## Стиль
[[styles/cinematic-orchestral]] оправдан масштабом бури; оркестр раскрывается лишь раз, у спасения.
